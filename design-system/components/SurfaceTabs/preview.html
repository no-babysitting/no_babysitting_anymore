Plan mode

? chưa có tài liệu Docs Cowork chỉ liệt kê các mode Manual, Auto và Skip.

Diễn giảiChọn Manual, rồi yêu cầu: "Lập kế hoạch, hỏi tôi chỗ còn mơ hồ, chờ tôi duyệt rồi mới làm."

  1. Desktop: mở bộ chọn mode dưới ô nhập và chọn Plan, chỉ áp dụng cho phiên này. Phím tắt Cmd/Ctrl+Shift+M.
  2. Web (claude.ai/code): chọn Plan trong dropdown mode.
  3. Duyệt kế hoạch xong mới cho Claude bắt đầu làm.
  1. Nhấn Shift+Tab tới khi thanh trạng thái hiện ⏸ plan mode on.
  2. Hoặc thêm /plan trước prompt, hoặc khởi động bằng claude --permission-mode plan.
  3. Ctrl+G để sửa kế hoạch trong editor trước khi duyệt.
